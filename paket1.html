Greenify




Misal :


X = Harga 1 Tas Laptop

Y = Harga 1 Lampu dari Sendok

Z = Harga 1 Ecoprint Mug

Model Matematika :


  1. 4x + 2y + z = 225.000
  2. x + y + 2z = 120.000
  3. 3x + 3y + 3z = 285.000

Penyelesaian:


Eliminasi pers 1. dan 2.


4x + 2y + z = 225.000 |*2| 8x + 4y + 2z = 480.000

x + y + 2z = 120.000 |*1| x + y + 2z = 120.000


_______________________________ _


7x + 3y = 330.000… 4.

Eliminasi pers 2. dan 3.


x + y + 2z = 120.000 |*3| 3x + 3y + 6z = 480.000

3x + 3y + 3z = 120.000 |*1| 6x + 6y + 6z = 120.000


_______________________________ _


-3x - 3y = -210.000… 5.

Eliminasi pers 4. dan 5.


7x + 3y = 330.000

-3x - 3y = -210.000


_______________________________ +


4x = 120.000

x = 120.000/4

x = 30.000

Substitusi x = 30.000 ke pers 4.


7x + 3y = 330.000

7*30.000 + 3y = 330.000

210.000 + 3y = 330.000

3y = 330.000 – 210.000

3y = 120.000

y = 120.000/3

y = 40.000

Substitusi x = 30.000 dan y = 40.000 ke pers 2.


x + y + 2z = 120.000

30.000 + 40.000 + 2z = 120.000

70.000 + 2z = 120.000

2z = 120.000 – 70.000

2z = 50.000

z = 50.000/2

z = 25.000

Jadi, kesimpulanya adalah :


  1. harga 1 Tas Laptop = 30.000
  2. harga 1 Lampu dari sendok = 40.000
  3. harga 1 Ecoprint Mug = 25.000
