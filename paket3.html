Serba Serbi




Misal :


X = Harga 1 Jam dinding Kertas

Y = Harga 1 Tas Laptop

Z = Harga 1 Lampu dari Botol kaca

Model Matematika :


  1. x + y + 2z = 120.000
  2. 2x + 2y + z = 165.000
  3. 2x + y + 3z = 185.000

Penyelesaian :


Eliminasi pers 1. dan 2.


x + y + 2z = 120.000 |*2| 2x + 2y + 4z = 480.000

2x + 2y + z = 165.000 |*1| 2x + 2y + z = 165.000


_______________________________ _


0 + 3z = 75.000

z = 75.000/3

z = 25.000

Eliminasi pers 2. dan 3.


2x + 2y + z = 165.000


_______________________________ _


y - 2z = -20.000… 4.

Substitusi z = 25.000 ke pers 4.


y - 2z = -20.000

y - 2*25.000 = -20.000

y - 50.000 = -20.000

y = -20.000 + 50.000

y = 30.000

Substitusi z = 25.000 dan y = 40.000 ke pers 1.


x + y + 2z = 120.000

x + 30.000 + 2*25.000 = 120.000

x + 80.000 = 120.000

x = 120.000 – 80.000

x = 40.000

Jadi, kesimpulanya adalah :


  1. harga 1 Jam dinding Kertas = 40.000
  2. harga 1 Tas Laptop = 30.000
  3. harga 1 Lampu dari Botol Kaca = 25.000
