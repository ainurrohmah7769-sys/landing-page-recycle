EcoShine




Misal :


X = Harga 1 Jam Kertas

Y = Harga 1 Tempat Flasdisk

Z = Harga 1 Tas Laptop

Model Matematika :


  1. 3x + 2y + z = 200.000
  2. 2x + y + 3z =195.000
  3. 4x + 3y + 2z = 295.000

Penyelesaian :


Eliminasi pers 1. dan 2.


3x + 2y + z = 200.000 |*1| 3x + 2y + z = 200.000

2x + y + 3z = 195.000 |*2| 4x + 2y + 6z = 120.000


_______________________________ _


-x - 5z = -190.000… 4.

Eliminasi pers 2. dan 3.


2x + y + 3z =195.000 |*3| 6x + 3y + 9z = 480.000

4x + 3y + 2z = 295.000 |*1| 4x + 3y + 2z = 295.000


_______________________________ _


2x + 7z = 290.000… 5.

Eliminasi pers 4. dan 5.


-x - 5z = -190.000 |*2| -2x + 10y + 9z = 480.000

2x + 7z = 290.000 |*1| 2x + 7z = 290.000


_______________________________ +


-3z = -90.000

z = -90.000/3

z = 30.000

Substitusi z = 30.000 ke pers 5.


2x + 7z = 290.000

2x + 7*30.000 = 290.000

2x + 210.000 = 290.000

2x = 290.000 – 210.000

2x = 80.000

x = 80.000/2

x = 40.000

Substitusi z = 30.000 dan x = 40.000 ke pers 1.


3x + 2y + z = 200.000

3*40.000 + 2y + 30.000 = 200.000

150.000 + 2y = 200.000

2y = 200.000 – 150.000

2y = 50.000

y = 50.000/2

y = 25.000

Jadi, kesimpulanya adalah :


  1. harga 1 Jam Kertas = 40.000
  2. harga 1 Tempat Flasdisk = 25.000
  3. harga 1 Tas Laptop = 30.000
